# CryptoWrapper

CryptoWrapper (`cw`) is a safer, simpler Go CLI wrapper around OpenSSL.

> [!WARNING]
> This project has not received an independent cryptographic security audit.

The first development release requires Go 1.24+ and OpenSSL 3.6.3+.

```sh
make build
./bin/cw version
```

Full command documentation will be added as the implementation lands.
